# Project Roadmap

## Phase 0 — Foundation

Repository, structure, backend, frontend, Docker, CI, validation.

## Phase 1 — Data Foundation

Public API, collection, cleaning, schema, PostgreSQL, Parquet.

## Phase 2 — Recommendation Models

Popularity, embeddings, similar books, synthetic users, interactions, ALS.

## Phase 3 — Hybrid Recommendation

Candidates, normalization, weighted hybrid, MMR, reasons.

## Phase 4 — Evaluation

Split, Precision@10, Recall@10, NDCG@10, Coverage, benchmark.

## Phase 5 — Serving

FastAPI services, recommendation APIs, runtime validation.

## Phase 6 — Product UI

Landing, recommendations, model comparison, evaluation dashboard.

Detailed Sprint and Task scope is defined separately by the Planning Agent.
